# 基础

单词、词性、语法

## 基础提升

| 周数        | 语法主线                        | 听说读写任务                    |
| --------- | --------------------------- | ------------------------- |
| 第 1–2 周   | 词性、主谓宾、be 动词、代词             | 自我介绍；读懂简单句；练习英语基本发音       |
| 第 3–4 周   | 一般现在时、一般疑问句、特殊疑问句           | 描述日常生活；听懂短对话；写简单句         |
| 第 5–6 周   | 名词单复数、冠词、介词、there be        | 描述房间、学校、城市；阅读短篇材料         |
| 第 7–8 周   | 现在进行时、一般过去时、一般将来时           | 描述正在做的事、过去经历和未来计划         |
| 第 9–10 周  | 情态动词、形容词、副词、比较级             | 表达喜好、能力和比较；练习短段落          |
| 第 11–12 周 | and、but、because、so、if 等连接方式 | 组织 5–8 句的短文；进行 1–2 分钟简单表达 |
## 语法

主 + 谓 + 宾

时态、be 动词、助动词

形容词、副词、介词短语

并列句、原因、条件、从句

# 听力

1. 第一遍：盲听。 不看文本，尝试理解主题和熟悉的词。
    
2. 第二遍：带着问题听。 判断人物、时间、地点或主要事件。
    
3. 第三步：对照文本。 找出听不懂的词、连读、弱读和不熟悉的表达。
    
4. 第四步：逐句跟读。 模仿发音、重音、语调和停顿。
    
5. 第五步：再次盲听。 检查自己是否能听懂之前没听明白的内容。

# 口语

先把简单的东西说明白，不追求复杂
# 阅读

放慢速度，精读

- 用中文概括文章在讲什么。
    
- 找出 3–5 个值得学习的词或搭配。
    
- 选 2–3 个句子，分析主谓宾和修饰成分。
    
- 合上文章，用简单英语复述主要内容。

# 写作

|能力阶段|写作训练|
|---|---|
|基础阶段|正确写出简单句，每天 5–8 句|
|初级进阶|把句子组成一个完整段落|
|中级阶段|练习主题句、理由、解释和例子|
|雅思阶段|练习 Task 1、Task 2，学习审题、结构和论证|
|冲刺阶段|限时写作、修改语法错误、强化逻辑与表达|
