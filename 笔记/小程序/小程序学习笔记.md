
# 事件系统

## 绑定事件

`bind` / `bind:` 绑定事件不会阻止冒泡

`catch` 绑定事件会阻止事件向上冒泡

`mut-bind` 互斥事件绑定，意思是：一个 `mut-bind` 触发后，如果事件冒泡到其他节点上，其他节点上的 `mut-bind` 绑定函数不会被触发，但 `bind` 绑定函数和 `catch` 绑定函数依旧会被触发。

需要在捕获阶段监听事件时，可以采用 `capture-bind`、`capture-catch` 关键字，后者将中断捕获阶段和取消冒泡阶段。

### dataset

用于在组件节点中可以附加一些自定义数据

自定义数据以 `data-` 开头，多个单词由连字符 `-` 连接。这种写法中，连字符写法会转换成驼峰写法，而大写字符会自动转成小写字符。如：

- `data-element-type` ，最终会呈现为 `event.currentTarget.dataset.elementType` ；
- `data-elementType` ，最终会呈现为 `event.currentTarget.dataset.elementtype` 。

### mark

使用 `mark` 来识别具体触发事件的 target 节点

当事件触发时，事件冒泡路径上所有的 `mark` 会被合并，并返回给事件回调函数
