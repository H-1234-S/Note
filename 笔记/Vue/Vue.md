# 计算属性

`computed` 接收一个回调函数，返回一个计算属性 `ref`，该 `ref` 同一般 `ref`

## 计算属性 vs 方法

虽然两种方式在得到的结果完全相同，但是过程是不同的

对于**计算属性**，**计算属性值会基于其响应式依赖被缓存**；一个计算属性仅会在其**响应式依赖更新时**才重新计算

计算属性默认是只读的
