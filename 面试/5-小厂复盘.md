# useEffect和useLayoutEffect

useEffect 是异步的，在浏览器绘制屏幕之后触发

useLayoutEffect 是同步的，在Paint阶段前触发

useLayoutEffect 用于解决屏幕闪烁
	例如：用户刷新页面后滚动位置不丢失

useEffect 主要用于**初始第三方库**和**响应外部变化**
# Tanstack Query和Fetch+useState

Tanstack Query 自己维护了一套缓存、自动去重、重试、还有状态
	其实在浏览器维护了一个缓存

Fetch+useState 需要自己手动维护加载、报错等状态、还要维护缓存和重试
# Ai流式输出

SEE 即基于HTTP的服务端单向推送技术

ai 流式输出本质就是服务端不断产生文本数据，然后客户端进行增量渲染

客户端自动重连，会拿着最后一个事件Id去服务器重连

**流程：**
	1. 客户端创建 EventSource 连接，携带 Accept：text/event-stream
	2. 服务端验证后，返回 Content-Type：text/event-stream
		注意：此时连接不中断
	3. 之后服务端不断发送文本事件
	4. 客户端根据边界触发 message 事件
