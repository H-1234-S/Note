# 宏任务、微任务、raf


> raf 在浏览器下一帧绘制前执行

```js
console.log(1)
setTimeout(() => console.log(2),0)
requestAnimationFrame(() => console.log(3))
Promise.resolve.then(() => console.log(4))
console.log(5)
```

requestAnimationFrame 和 setTimeout 执行的先后顺序取决于浏览器下一帧何时渲染
