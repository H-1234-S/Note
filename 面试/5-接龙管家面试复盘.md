# React 为什么要将状态视为不可变

> React 通过判断引用是否发生变化来判断状态是否更新

`React` 使用 `Object.is` 来判断状态是否发生变化，也就是使用浅比较

> React 为什么不用深比较

React 为了性能其实使用的是浅比较，时间复杂度为 O(1)；如果每次都深比较那么时间复杂度就是 O(n)

> 不可变数据使更新更容易推导

> 有利于 React 的性能优化

例如使用 `memo`，`memo` 也是进行浅比较

# 为什么要有 async await

`async await` 是为了用同步代码的写法编写异步代码；解决了 `Promise` 链式调用的复杂性
## async await 编译后是什么

`async/await` 本质是 Promise 的语法糖，但在编译阶段，通常会被转换成 Generator + 自动执行器（如 `__awaiter` 辅助函数）来模拟暂停与恢复执行，而不是简单地转换成 `.then()` 链。

``` js
function* g() {
    const a = yield getA();

    const b = yield getB(a);

    return b;
}
```

``` js
const it = g();

it.next();
```
