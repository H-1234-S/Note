# JS 存储

## cookie

设计目的是为了解决如何在多次请求之间携带状态

大小通常是 4kb，每次随请求发送，携带在 headers 中
## LocalStorage

本地持久化存储数据，永久有效，除非手动清除，大小通常是 5mb

只能存储字符串，对于对象可以用 `JSON.stringify()` 转为字符串存储

``` js
localStorage.setItem("myCat", "Tom")

localStorage.getItem("myCat")

localStorage.removeItem("myCat")

// 移除所有
localStorage.clear();
```
## SessionStorage

SessionStorage 与 LocalStorage 类似，但是 SessionStorage 是会话状态，意思是当关闭标签页面数据就会被清空

``` js
// 保存数据到 sessionStorage
sessionStorage.setItem("key", "value");

// 从 sessionStorage 获取数据
let data = sessionStorage.getItem("key");

// 从 sessionStorage 删除保存的数据
sessionStorage.removeItem("key");

// 从 sessionStorage 删除所有保存的数据
sessionStorage.clear();
```
## IndexedDB

IndexedDB 可以看作为存储在浏览器内存中的**非关系型数据库**，用于在客户端存储大量的结构化数据（也包括文件/二进制大型对象（blob））
