
在 Next.js 中，最核心的转变是：**逻辑从浏览器端向服务器端迁移**。

---

### 1. 路由系统 (Routing) —— 框架的骨架

Next.js 的 App Router 是基于文件系统的。

- **层级结构**：理解 `layout.tsx`（布局）、`page.tsx`（页面）、`template.tsx` 的嵌套关系。
    
- **动态路由**：掌握 `[id]` 这种文件夹命名，以及如何通过 `params` 获取参数。
    
- **平行路由与拦截路由**：这是进阶知识点，用于处理复杂的 UI（如弹窗路由、多面板仪表盘）。

---

### 2. 渲染模式 (Rendering) —— 最核心的面试题

这是 Next.js 与普通 React 项目最大的区别。

- **服务端组件 (Server Components)**：默认所有组件都是服务端组件。要弄清楚为什么在服务器渲染组件性能更好（减少 JS 体积、SEO 友好）。
    
- **客户端组件 (Client Components)**：明确什么时候加 `'use client'`（涉及 `useState`、`useEffect` 或浏览器 API 时）。
    
- **混合渲染**：学习如何将客户端组件嵌套在服务端组件中。

---

### 3. 数据获取与缓存 (Data Fetching & Caching)

Next.js 极大地增强了原生的 `fetch`。

- **RSC 数据获取**：直接在服务端组件里写 `async/await fetch`，不需要 `useEffect`。
    
- **缓存机制 (Revalidation)**：掌握如何设置 `next: { revalidate: 3600 }` 来实现数据的定时刷新（ISR）。
    
- **Server Actions**：**重点学习！** 这是 Next.js 处理表单提交、修改数据库的新标准，它让你像调用本地函数一样调用后端接口。

---

### 4. 性能优化 (Optimization)

这是 Next.js 帮我们做好的“开箱即用”功能，但你需要知道原理：

- **Image 组件**：自动进行图片压缩、懒加载和 WebP 转换。
    
- **字体优化 (`next/font`)**：自动托管本地字体，解决布局偏移（CLS）。
    
- **脚本优化 (`next/script`)**：控制第三方脚本（如统计代码）的加载时机。

---

### 5. 中间件与认证 (Middleware & Auth)

由于你有找实习的需求，**身份认证**是项目必做的功能。

- **Middleware**：学习如何在请求到达页面前拦截它（比如：未登录用户访问 `/admin` 直接重定向到 `/login`）。
    
- **NextAuth.js (Auth.js)**：这是 Next.js 生态中最流行的认证库，支持 OAuth（GitHub、Google 登录）和凭据登录。

|---|---|---|
|**第一阶段：上手**|跟着官网做 `Dashboard` 教程|能够独立解释 `page` 和 `layout` 的区别。|
|**第二阶段：打通**|使用 **Route Handlers** 或 **Server Actions** 连接数据库|理解数据是怎么从客户端传到服务器并存入数据库的。|

|**第四阶段：面试**|总结 **RSC (服务端组件)** 的优缺点|能讲清楚为什么 Next.js 比单页面 React 应用（SPA）快。|
