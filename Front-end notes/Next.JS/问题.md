# 边界问题

## RSC组件

Server Component 运行在服务器环境，服务器会将这个组件转化成一种名为 **RSC Payload** 的 JSON 数据结构。

## RCC组件

Client Component 运行在浏览器环境

## 边界

Server Component 组件可以包含 Client component 组件

但客户端组件不能直接通过 `import` 包含服务端组件（除非使用 `children` 插槽模式）。

### 插槽模式

当你通过 `children` 的方式把服务端组件传给客户端组件时，客户端组件并不需要知道服务端组件内部是怎么运作的。

- **对客户端组件而言：** `children` 只是一个预先生成的“UI 块”。它就像一个已经渲染好的 React 元素（React Element），客户端组件只需要在自己的 DOM 结构里找个位置把它“放进去”即可。
    
- **对浏览器而言：** 浏览器下载客户端组件的 JavaScript 代码进行水合（Hydration），但对于 `children` 部分，它只需要负责显示，不需要再次运行那些属于服务器的逻辑。
