# 00. 学习路线

## 阶段一：能把 PostgreSQL 用起来

目标：

- 理解数据库、表、行、列、主键、外键。
- 熟悉 `psql` 基本操作。
- 会写基础 `SELECT / INSERT / UPDATE / DELETE`。
- 会使用 `WHERE / ORDER BY / LIMIT / JOIN / GROUP BY`。

建议产出：

- 能独立设计 3 到 5 张有关联的表。
- 能写出常见业务查询，例如订单列表、用户消费统计、最近登录记录。

## 阶段二：写出可靠的数据模型

目标：

- 理解数据类型、约束、默认值、外键级联。
- 理解 Schema、命名规范、迁移脚本。
- 初步掌握事务。

建议产出：

- 为练习项目补齐主键、唯一约束、检查约束和外键。
- 能解释为什么约束应该尽量放在数据库层，而不只放在应用层。

## 阶段三：写出更强的 SQL

目标：

- 熟练使用 CTE、窗口函数、JSONB、数组、递归查询。
- 理解 PostgreSQL 和“只会标准 SQL”的差别。

建议产出：

- 写出排行榜、同比环比、树形结构查询、JSON 字段过滤。

## 阶段四：性能优化

目标：

- 理解索引类型：B-tree、GIN、GiST、BRIN、Hash。
- 会阅读 `EXPLAIN` 查询计划。
- 知道统计信息、选择性、回表、顺序扫描不是一定坏事。

建议产出：

- 对慢查询建立合适索引。
- 对同一个查询比较加索引前后的执行计划。

## 阶段五：安全、运维与生产实践

目标：

- 理解角色、权限、RLS。
- 会备份恢复。
- 理解连接池、WAL、复制、VACUUM、Autovacuum。
- 知道应用开发时如何避免 SQL 注入、连接耗尽、长事务。

建议产出：

- 本地完成一次 `pg_dump` 和恢复。
- 给多租户表启用 RLS。
- 在 Node.js 或 Prisma 项目里正确使用连接池和迁移。
