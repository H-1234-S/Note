# 01. 快速上手

## PostgreSQL 是什么

PostgreSQL 是一个开源关系型数据库，强调 SQL 标准、事务一致性、扩展能力和可靠性。它既能处理传统业务表，也支持 JSONB、全文搜索、地理信息扩展、向量扩展等现代应用场景。

## psql 常用命令

```sql
-- 查看当前连接信息
\conninfo

-- 列出数据库
\l

-- 切换数据库
\c study

-- 列出表
\dt

-- 查看表结构
\d users

-- 开启耗时显示
\timing

-- 退出
\q
```

## 创建数据库和表

```sql
CREATE DATABASE study;
```

连接到 `study` 后：

```sql
CREATE TABLE users (
  id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  email TEXT NOT NULL UNIQUE,
  name TEXT NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

## 插入数据

```sql
INSERT INTO users (email, name)
VALUES
  ('alice@example.com', 'Alice'),
  ('bob@example.com', 'Bob');
```

## 查询数据

```sql
SELECT id, email, name, created_at
FROM users
ORDER BY id;
```

## 修改和删除

```sql
UPDATE users
SET name = 'Alice Zhang'
WHERE email = 'alice@example.com';

DELETE FROM users
WHERE email = 'bob@example.com';
```

## 防止误操作

`UPDATE` 和 `DELETE` 一定先写 `WHERE`，并先用 `SELECT` 验证影响范围：

```sql
SELECT *
FROM users
WHERE email = 'alice@example.com';
```
