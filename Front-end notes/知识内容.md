
# 单例模式

## useState惰性初始化

``` ts
const [trpcClient] = useState(() =>
  createTRPCClient<AppRouter>({
    links: [
      httpBatchLink({
        transformer: superjson,
        url: getUrl(),
      }),
    ],
  }),
);
```

利用 useState 的惰性初始化（Lazy Initialization）特性，确保这个客户端实例只会被创建一次。
  
React 只在第一次 render 时调用这个函数；只有在组件卸载时会清空

## 服务器端单例

``` ts
// 服务端和浏览器的 Query Client 管理策略不同
let browserQueryClient: QueryClient | undefined;

function getQueryClient() {
  if (typeof window === 'undefined') {
    // 服务端：每次都创建新的 client
    return makeQueryClient();
  }
  
  // 浏览器：使用单例 client
  if (!browserQueryClient) {
    browserQueryClient = makeQueryClient();
  }
  return browserQueryClient;
}
```

浏览器是每个用户一个JS运行环境

服务器是所有用户共享一个进程

服务器代码执行流程：服务器启用时执行一次；用户调用该代码执行一次


# 性能优化

## httpbatchlink网络请求优化

``` ts
const [trpcClient] = useState(() =>
  createTRPCClient<AppRouter>({
    links: [
      httpBatchLink({
        transformer: superjson,
        url: getUrl(),
      }),
    ],
  }),
);
```

httpbatchlink用于请求合并，将多个请求合并成一个请求

**特点：** 降低了 HTTP Header 的重复传输和 TCP/TLS 连接的建立成本。

```
多个请求：
  trpc.voices.getAll.query()
  trpc.generations.getAll.query()

自动合并为单个 HTTP 请求：
  POST /api/trpc/voices.getAll,generations.getAll

响应返回后再拆分给各个调用
```
