## 1. 核心导入指令 (Importing)

在 v4.0 中，你不再需要像旧版本那样写三个独立的 `@tailwind` 指令，取而代之的是单一的导入：

CSS

```
@import "tailwindcss";
```

- **作用**：引入 Tailwind 的整个运行时引擎、预设样式（Preflight）和工具类定义。
    
- **位置**：必须放在 CSS 文件的最顶部。
    

---

## 2. 主题配置指令 (Theming)

这是 v4.0 最大的变革。所有的自定义配置（颜色、间距、字体）都通过 `@theme` 块完成。

CSS

```
@theme {
  --color-brand: #3b82f6;      /* 自动生成 text-brand, bg-brand */
  --font-display: "Inter";     /* 自动生成 font-display */
  --spacing-15: 3.75rem;       /* 增加自定义间距单位 */
}
```

- **作用**：定义设计令牌（Design Tokens）。
    
- **原理**：Tailwind 会自动将这些 CSS 变量映射为可用的原子类。
    
## 3. 层级管理指令 (Layering)

虽然 v4 更加自动化，但手动定义层级依然是处理样式优先级的最佳实践。

|**层级 (Layer)**|**指令语法**|**适用场景**|**优先级**|
|---|---|---|---|
|**Base**|`@layer base { ... }`|HTML 标签重置（如 `h1`, `a`）|最低|
|**Components**|`@layer components { ... }`|提取复杂的 UI 组件类（如 `.card`）|中|
|**Utilities**|`@layer utilities { ... }`|自定义单功能工具类|最高|

**示例代码：**

``` css
@layer base {
  button {
    @apply cursor-pointer focus:outline-none;
  }
}

@layer components {
  .btn-primary {
    @apply bg-brand px-4 py-2 rounded text-white;
  }
}
```

---

## 4. 样式提取指令 (Applying)

这是开发者最常用的“胶水”指令，用于在 CSS 中复用原子类。

CSS

```
.my-custom-class {
  @apply flex items-center justify-between p-4 bg-gray-100;
}
区别：一个是传统的 CSS 组合，一个是真正的 Tailwind 原子类扩展。
@utility flex-center {
  @apply mt-2 flex items-center justify-between gap-2;
}
```

- **作用**：将多个 Tailwind 工具类打包进一个自定义的选择器中。
    
- **禁忌**：不要在 React 组件内部通过 `@apply` 大量复用样式，建议优先使用组件化（Component Composition）。

---

## 5. 自定义变体指令 (Custom Variants)

当你需要根据特定逻辑（如暗黑模式、权限、特定状态）切换样式时使用。

CSS

```
/* 定义 dark 变体 */
@custom-variant dark (&:where(.dark, .dark *));

/* 定义一个鼠标悬停且是激活状态的变体 */
@custom-variant hover-active (&:hover:active);
```

- **作用**：创建自定义的前缀（如 `dark:`, `hover-active:`）。
    
- **优势**：在 HTML 中使用时，语法保持一致：`<div class="hover-active:opacity-50">`。
    

---

## 6. 自定义工具类指令 (Custom Utilities)

如果你有一些 Tailwind 没提供的特殊 CSS 属性，可以用这个指令。

CSS

```
@utility content-auto {
  content-visibility: auto;
}
```

- **作用**：创建一个全新的原子类名。
    
- **用法**：在 HTML 中直接调用 `<div class="content-auto">`。
    

---

## 💡 开发建议 (针对实习面试)

1. **CSS-First 思路**：在面试中提到 v4.0 时，重点强调它消除了 JavaScript 配置文件，让配置回归 **原生 CSS 变量**。
    
2. **权重控制**：深刻理解 `@layer`。如果面试官问“为什么我的自定义 CSS 被覆盖了？”，答案通常是“没有正确放置在 `@layer utilities` 中”。
    
3. **按需生成**：所有的指令最终都会被 Tailwind 的编译器扫描，只有被用到的部分才会被打包，这保证了产物性能。
    

---

### 📝 总结表

|**指令**|**核心功能**|
|---|---|
|**`@import "tailwindcss"`**|启动引擎|
|**`@theme`**|定义颜色、字体等“设计规范”|
|**`@apply`**|在 CSS 里组合使用原子类|
|**`@layer`**|安排样式的优先级顺序（Base > Components > Utilities）|
|**`@custom-variant`**|自定义样式前缀（如暗黑模式、自定义状态）|
|**`@utility`**|注册一个新的单一功能类|
