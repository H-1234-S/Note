## 1. 执行上下文与预编译 (Execution Context) 🏗️

### 核心知识点

- **三种上下文**：全局执行上下文、函数执行上下文、`eval`（不推荐）。
    
- **三个组成部分**：变量对象（VO/AO）、作用域链（Scope Chain）、`this` 绑定。
    
- **提升优先级**：**函数声明提升 > 变量声明提升**。同名的 `var` 变量声明会被忽略，但赋值会覆盖函数。
    

### 代码案例：提升陷阱

``` js
console.log(a); // [Function: a] - 函数提升优先级高
var a = 1;      // 执行到此处时，a 从函数变为 1

function a() { console.log(2); }

console.log(a); // 1
var a = 3;
console.log(a); // 3
// a();         // 报错：TypeError: a is not a function (此时 a 是 3)
```

## 2. 块级作用域与暂时性死区 (TDZ) 🚫

### 核心知识点

- **let/const**：引入了块级作用域，不存在传统的变量提升。
    
- **TDZ 原理**：进入作用域到变量声明完成之前的区域。在此区域访问变量会触发 `ReferenceError`。
    
### 代码案例：TDZ 报错

``` js
let x = 10;
function target() {
    // 引擎发现作用域内有 x，于是锁定该作用域的 x
    console.log(x); // ReferenceError: Cannot access 'x' before initialization
    let x = 20;
}
```

## 3. 内存管理与垃圾回收 (GC) ♻️

### 核心知识点

- **V8 分代回收**：
    
    1. **新生代**：存放存活时间短的对象，使用 **Scavenge 算法**（From/To 空间对调）。
        
    2. **老生代**：存放存活时间长的对象，使用 **Mark-Sweep（标记清除）** 和 **Mark-Compact（标记整理）**。
        
- **标记起点**：从 **根对象 (Root Set)** 开始递归标记。
    
### 代码案例：闭包导致的意外“长寿”

``` js
let theThing = null;
function replaceThing() {
  let originalThing = theThing;
  // 即使 unused 没被调用，它持有了 originalThing
  let unused = function () {
    if (originalThing) console.log("hi");
  };
  theThing = {
    longStr: new Array(1000000).join('*'),
    someMethod: function () {} // someMethod 和 unused 共享词法环境，导致 originalThing 不被回收
  };
}
setInterval(replaceThing, 1000); // 持续运行会导致内存泄漏
```

---

- 面试时提到闭包，一定要主动谈及 **V8 的静态分析优化**。
    
- 解释变量提升时，使用 **“预编译阶段”** 和 **“执行阶段”** 这两个术语显得更专业。
