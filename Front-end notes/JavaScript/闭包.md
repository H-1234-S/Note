## 前置储备知识

要彻底理解闭包，你必须先搞懂这两个底层概念：

### 1. 作用域 (Scope)

指的是变量的可访问范围。JavaScript 采用的是**词法作用域（Lexical Scoping）**，这意味着变量的作用域在**代码书写阶段**就已经确定了，而不是执行阶段。

### 2. 执行上下文与调用栈 (Call Stack)

当一个函数执行完毕后，通常情况下，它的执行上下文会被从栈中弹出，内部的变量也会被垃圾回收机制（GC）销毁。**闭包则是这个规则的“特例”。**

---

## 什么是闭包？

**闭包的定义：** 一个函数和它周围状态（词法环境）的引用捆绑在一起，这个组合就是闭包。

通俗点说：**闭包让你可以在一个内层函数中，访问到其外层函数的作用域。** 即使外层函数已经执行结束了，那些被引用的变量依然“活”在内存里。

---

## 为什么需要闭包？

作为工程师，我们追求的是**封装性**和**私有化**。

### 1. 模拟私有变量

JavaScript 原生长期缺乏私有属性，闭包是实现“数据隐藏”的最佳手段。

``` js
function createCounter() {
  let count = 0; // 私有变量，外部无法直接修改
  return {
    increment() { count++; return count; },
    decrement() { count--; return count; },
    getCount() { return count; }
  };
}

const myCounter = createCounter();
console.log(myCounter.increment()); // 1
console.log(myCounter.increment()); // 2
// console.log(count); // 报错：count is not defined
```

### 2. 柯里化与预设参数

闭包允许我们 **“记住”** 某些配置参数。

``` js
function makeAdder(x) {
  return function(y) {
    return x + y;
  };
}

const add5 = makeAdder(5);
console.log(add5(10)); // 15
```

---

## 闭包的深度解析（核心机制）

当 `makeAdder(5)` 执行时，它创建了一个环境，其中 `x = 5`。通常这个环境该被销毁，但因为返回的匿名函数依然持有对 `x` 的引用，JavaScript 引擎会把这个 `x` 移动到**堆内存**中保留下来。

**知识点补全：**

- **内存泄漏风险**：由于闭包会阻止变量被回收，如果大量使用且不及时释放引用，可能导致内存占用过高。
    
- **循环中的闭包**：这是经典面试题（用 `var` 在 `for` 循环中定义 `i` 导致的问题），现在我们通常用 `let` 的块级作用域来解决，其实 `let` 在循环中每次迭代都会创建一个新的闭包环境。

## 手写实战 

### 1. 手写单例模式 (Singleton)

确保一个类只有一个实例。

``` js
const Singleton = (function() {
  let instance; // 闭包变量，存储唯一实例

  function createInstance() {
    return { name: "I am the only one" };
  }

  return {
    getInstance: function() {
      if (!instance) {
        instance = createInstance();
      }
      return instance;
    }
  };
})();

const a = Singleton.getInstance();
const b = Singleton.getInstance();
console.log(a === b); // true
```

### 2. 手写防抖函数 (Debounce)

在前端性能优化中，防抖利用闭包存储 `timer` 变量。

``` js
function debounce(fn, delay) {
  let timer = null; // 闭包变量，记录定时器

  return function(...args) {
    // 如果已经在计时，清空它重新计
    if (timer) clearTimeout(timer);
    
    timer = setTimeout(() => {
      fn.apply(this, args);
      timer = null;
    }, delay);
  };
}

// 使用示例
const handleScroll = debounce(() => console.log('Scrolled!'), 300);
window.addEventListener('scroll', handleScroll);
```

## 生命周期

在正常的 JavaScript 执行环境中，闭包的生命周期遵循以下逻辑：

- **诞生：** 当一个内部函数引用了外部函数的变量，并且这个内部函数被返回或存储到外部时，闭包产生。
    
- **存活：** 只要这个内部函数还在被引用，它所“捕获”的变量就会一直驻留在内存中，不会被垃圾回收（GC）。
    
- **销毁：** 当没有任何变量指向这个内部函数时，闭包占用的内存会被回收。
