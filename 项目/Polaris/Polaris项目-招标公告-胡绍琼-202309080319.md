**项目概况：**

Polaris 是一个 AI 驱动的浏览器端在线 IDE。用户登录后可创建/导入项目，在线编辑代码，通过 WebContainer 运行预览，并与 AI Agent 对话让 AI 自动读写项目文件。系统需支持日均 500 次访问，并发用户不低于 50 人，AI 响应延迟不超过 10 秒。

**核心功能模块：**

- **用户认证**：基于 Clerk 的多平台登录（GitHub OAuth），支持会话管理与权限校验
- **项目管理**：新建项目、通过 Prompt 创建项目、GitHub 仓库导入/导出、项目重命名与配置
- **文件系统**：支持层级目录结构，创建/重命名/删除文件或文件夹，文本与二进制文件分别存储
- **在线编辑器**：基于 CodeMirror 6 的代码编辑，语法高亮、代码补全、Ghost Text 建议、Quick Edit
- **AI 对话**：AI Agent 通过工具（Tools）读写项目文件，支持多轮对话、消息取消与状态同步
- **在线预览**：WebContainer 浏览器端运行项目，自动安装依赖并启动 Dev Server
- **后台任务**：Inngest 编排 AI 消息处理、GitHub 导入/导出等长任务

**技术栈要求：**

| 层级 | 技术要求 |
|------|----------|
| 前端框架 | Next.js App Router（React 18+） |
| 数据库 | Convex（实时同步数据库） |
| 认证 | Clerk（支持 GitHub OAuth） |
| 后台任务 | Inngest（事件驱动任务编排） |
| AI 能力 | Vercel AI SDK + 大语言模型（如 DeepSeek） |
| 编辑器 | CodeMirror 6 |
| 预览运行时 | WebContainer |
| 状态管理 | Zustand |
| UI 组件 | shadcn/ui + Radix + Lucide Icons |
| 错误追踪 | Sentry |
| 部署 | Vercel / 阿里云 |
