## 2. 成本估算方法

## 5. 成本控制措施

1. **AI 调用优化**：使用模型缓存与 Prompt 压缩，降低 LLM API 调用量约 20%
2. **开源优先**：CodeMirror 6、shadcn/ui、Radix 等核心组件均为开源免费
3. **Serverless 弹性**：Vercel + Convex + Inngest 均按量计费，开发测试期成本极低
4. **自动化测试**：CI/CD 集成自动化测试流水线，减少人工回归测试成本
5. **需求冻结机制**：设计阶段冻结需求，变更走 CCB 审批，控制范围蔓延
6. **监控告警**：Sentry 全链路错误追踪，快速定位问题，减少故障排查成本
