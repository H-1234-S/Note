# 1. 想法

**AI 文本可视化教学编排工具**：把一段长文本，变成学生更容易理解的视频讲解。

AI 输出的长文本通常有几个问题：

1. 信息密度高，但结构不够教学化。
2. 只有文字，没有画面、节奏、重点提示。
3. 用户需要自己读、自己理解，学习成本高。
4. 内容可能很长，不适合直接朗读成视频。
5. 缺少例子、图示、动画、对比、流程图、时间线等教学元素。

所以工具核心目标应该是：

> 把 AI 生成的长文本，自动改写成适合“看视频学习”的内容，并生成可视化讲解视频。

# 2. 步骤/难点

1. **输入文本**  
    用户输入一段 AI 回答、文章、教材内容、知识点说明等。
    
2. **内容理解与拆解**  
    系统先分析文本：
    
    - 主题是什么？
    - 适合什么学习人群？
    - 有哪些核心概念？
    - 哪些地方需要举例？
    - 哪些地方适合做图？
    - 哪些地方适合做动画？
    - 哪些内容可以删减？
3. **生成教学脚本**  
    把原文改成视频脚本，例如：
    - 开场引入
    - 分段讲解
    - 旁白文案
    - 屏幕文字
    - 每一幕的画面说明
    - 动画建议
    - 例子/类比
    - 总结回顾
4. **生成分镜**  
    比如：

|镜头|旁白|画面|动画|
|---|---|---|---|
|1|今天我们讲什么是大模型|标题 + AI 图标|标题淡入|
|2|可以把大模型理解成一个会预测下一个词的系统|输入框、词语逐个出现|词语滚动|
|3|它不是在真正思考，而是在根据上下文生成最可能的内容|概率条、路径选择|高亮最大概率|

5. **生成视觉素材**  
    根据内容生成：
    - 图标
    - 流程图
    - 信息图
    - 动画场景
    - 人物讲解
    - 背景图
    - 公式/代码/图表
    - 关键词卡片
6. **合成视频**  
    最后把这些组合起来：
    - 旁白语音 TTS
    - 字幕
    - 背景音乐
    - 动画
    - 画面
    - 镜头切换
    - 导出 MP4


# 3. 版本

## 3.1 第一版

> 文本转可视化课件视频

用户输入长文本后，系统输出：

- 精简教学脚本
- 自动分段
- 每段生成一页可视化幻灯片
- 自动配旁白
- 自动生成字幕
- 导出视频

## 3.2 第二版

> AI 自动分镜动画视频

在 MVP 基础上增加：

- 每个知识点自动选择表现形式
- 流程型内容生成流程动画
- 对比型内容生成左右对比动画
- 时间型内容生成时间线
- 抽象概念生成类比动画
- 数据型内容生成图表动画

## 3.3 第三版

> 交互式教学视频生成器

用户可以编辑：

- 脚本
- 分镜
- 旁白风格
- 视觉风格
- 视频比例
- 角色形象
- 动画节奏
- 重点内容
- 目标人群

# 4. 注意

生成的不应该是视频，而是面向教学的表达

> 文本 → 理解 → 教学重构 → 可视化设计 → 视频生成
