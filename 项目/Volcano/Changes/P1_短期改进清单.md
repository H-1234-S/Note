## 2. Retry 当前不支持 Resume

### 实际代码
```ts
// project.service.ts:407 — retryGeneration
// 始终创建新的 generationJob，从头开始，不检查已生成的资源
```

❌ 问题：Storyboard 已生成但仍然调用 LLM 重新生成，浪费成本

### 建议方案
```ts
export async function retryGeneration(projectId, userId) {
  const project = await prisma.project.findUnique({
    include: {
      storyboardVersions: { orderBy: { versionNumber: 'desc' }, take: 1 },
      generationJobs: { orderBy: { createdAt: 'desc' }, take: 1 }
    }
  });

  // 判断从哪个步骤恢复
  const lastStoryboard = project.storyboardVersions[0];
  const lastJob = project.generationJobs[0];

  let resumeFrom: 'storyboard' | 'audio' | 'render' = 'storyboard';

  if (lastStoryboard) {
    const hasAllAudio = await checkAllScenesHaveAudio(lastStoryboard.id);
    if (hasAllAudio) {
      resumeFrom = 'render';
    } else {
      resumeFrom = 'audio';
    }
  }

  // 创建新 Job 时传入 resumeFrom
  const job = await prisma.generationJob.create({
    data: {
      // ... existing fields
      inputParams: JSON.stringify({
        ...existingParams,
        resumeFrom  // Inngest 据此跳过已完成的步骤
      })
    }
  });
}
```

## 5. 缺少 Redis 但 TDD 依赖 Redis

### TDD 依赖 Redis 的场景
- 缓存 TTS 语音列表（10.2.1）
- 限流（12.3 - rate-limiter-flexible）
- 幂等去重窗口

### 当前风险
如果 Redis 不可用（MVP 阶段可能没部署）：
- 限流降级为内存计数器（不可靠，多实例不一致）
- TTS 语音列表每次请求都调用 Provider API

### 建议
```ts
// 在 src/lib/env.ts 中标记 Redis 为可选
REDIS_URL: z.string().optional()

// 在 service 中降级
const cache = redisUrl 
  ? new RedisCache(redisUrl) 
  : new InMemoryCache(); // 单实例内存缓存
```
