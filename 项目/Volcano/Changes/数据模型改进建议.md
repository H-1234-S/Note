# 数据模型改进建议

## 基于实际 schema.prisma 的改进

### 1. Asset 表 - 解决复用隐患

**当前问题**：
```prisma
model Asset {
  projectId String? // 可为空，支持复用
}
```

❌ **问题**：
- 音频被多个项目复用时，删除其中一个项目会导致其他项目的音频丢失
- 无法追踪哪些项目正在使用这个 Asset

✅ **解决方案 A（推荐）**：增加多对多关联表
```prisma
model ProjectAsset {
  id        String   @id @default(cuid())
  projectId String
  project   Project  @relation(fields: [projectId], references: [id], onDelete: Cascade)
  assetId   String
  asset     Asset    @relation(fields: [assetId], references: [id], onDelete: Cascade)
  role      String   // audio, image, video, thumbnail, storyboard_json
  createdAt DateTime @default(now())

  @@unique([projectId, assetId, role])
  @@index([assetId])
  @@map("project_asset")
}

model Asset {
  // ... 现有字段
  projectId        String?          // 保留，记录首次创建者
  projectAssets    ProjectAsset[]   // 新增：多对多关联
  
  // 删除前检查逻辑：
  // SELECT COUNT(*) FROM project_asset WHERE assetId = ?
  // 如果 count > 0，则不删除
}
```

✅ **解决方案 B（简单）**：Asset 增加引用计数
```prisma
model Asset {
  // ... 现有字段
  referenceCount Int @default(1)  // 引用计数
  
  // 使用时 +1，删除时 -1
  // 当 referenceCount = 0 且 lifecycleStatus = 'orphaned' 时才真正删除
}
```

**建议**：生产环境使用方案 A，开发阶段可先用方案 B

### 2. UsageRecord 表 - 补充额度追踪

**当前问题**：
```prisma
model UsageRecord {
  resourceType String // ai_tokens, render_minutes, storage_gb
  quantity     Float
}
```

❌ **无法回答**：
- 用户今天生成了几个视频？（达到每日限额了吗？）
- 用户本月消耗了多少 tokens？

✅ **解决方案**：增加字段
```prisma
model UsageRecord {
  id              String   @id @default(cuid())
  userId          String
  user            User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  
  // 现有字段
  resourceType    String   // ai_tokens, render_minutes, storage_gb
  provider        String?
  quantity        Float
  unitCost        Float?
  totalCost       Float?
  metadata        String?  @db.Text
  recordedAt      DateTime @default(now())
  
  // 新增字段
  projectId       String?  // 关联到具体项目
  project         Project? @relation(fields: [projectId], references: [id], onDelete: SetNull)
  quotaType       String?  // daily_generation_count, monthly_token_limit, daily_render_minutes
  quotaConsumed   Int?     // 本次消耗的额度数量（如：生成1个视频 = 1）
  
  @@index([userId, recordedAt])
  @@index([userId, quotaType, recordedAt]) // 新增：用于额度查询
  @@index([resourceType])
  @@map("usage_record")
}
```

**额度检查查询**：
```typescript
// 检查今日生成次数
const todayStart = new Date();
todayStart.setHours(0, 0, 0, 0);

const todayCount = await prisma.usageRecord.aggregate({
  where: {
    userId,
    quotaType: 'daily_generation_count',
    recordedAt: { gte: todayStart }
  },
  _sum: { quotaConsumed: true }
});

const remaining = DAILY_LIMIT - (todayCount._sum.quotaConsumed || 0);
```

### 4. GenerationJob 表 - 补充恢复机制

**当前问题**：Resume 重试时需要查询多张表判断进度

✅ **解决方案**：增加进度追踪
```prisma
model GenerationJob {
  id            String     @id @default(cuid())
  // ... 现有字段
  
  // 新增：进度追踪
  completedSteps Json?     // { storyboard: true, audio: ["scene1", "scene2"], timeline: false }
  currentStep    String?   // storyboard, audio, timeline, render
  
  @@map("generation_job")
}
```

**重试逻辑简化**：
```typescript

const steps = job.completedSteps as {

// 直接判断从哪里恢复
if (!steps.storyboard) {
```

### 5. Project 表 - 补充并发控制

**当前实现**：状态字段是字符串
```prisma
status String @default("queued")
```

✅ **建议**：改为 Enum（类型安全）
```prisma
enum ProjectStatus {
  draft
  queued
  generating_storyboard
  storyboard_ready
  generating_audio
  calculating_timeline
  rendering
  completed
  failed
  cancelled
}

model Project {
  status ProjectStatus @default(queued)
}
```

**并发控制**：
```typescript
// 创建项目前检查
const runningStates: ProjectStatus[] = [
  'queued', 'generating_storyboard', 'storyboard_ready',
  'generating_audio', 'calculating_timeline', 'rendering'
];

const runningCount = await prisma.project.count({
  where: {
    userId,
    status: { in: runningStates }
  }
});

if (runningCount >= 1) { // 限制为 1
  throw new TRPCError({ 
    code: 'BAD_REQUEST',
    message: '您有正在生成的项目，请等待完成后再试' 
  });
}
```
