# Novabase — 云端 BaaS 全栈平台（类 Supabase）

**项目描述**：在云端为开发者提供开箱即用的后端能力。用户创建「组织 → 项目」后，平台自动为其分配独立的数据库 Schema，并即时提供自动生成的 REST API、Realtime 实时数据订阅、在线建表与 SQL 编辑器、对象存储以及项目级独立认证体系，让用户「建完表即可用」。

**技术栈**：Next.js / TypeScript / Tailwind / Shadcn / NestJS / Drizzle ORM / Neon Serverless Postgres / Socket.IO / JWT / Monaco Editor / TanStack Table / UploadThing / pnpm Monorepo

**核心技术攻克**：

- **端到端类型安全**：采用 Drizzle ORM 定义数据库 Schema，通过 `$inferSelect` / `$inferInsert` 自动推导数据行类型；并沉淀 `@novabase/types`、`@novabase/constants` 共享包，在 pnpm Monorepo 中让前后端复用同一份类型与常量定义，从数据库 Schema 到前端调用实现完整的类型链路。

- **多租户数据隔离**：设计 Schema-per-Project 架构，每个项目独享一个 PostgreSQL 命名空间，所有 SQL 强制携带 schema 前缀；SQL 编辑器执行前通过 `SET LOCAL search_path` 限定可见范围，并校验项目密钥中的 `projectId` 与 URL 资源是否匹配，实现租户级数据隔离与越权防护。

- **Realtime 实时订阅**：打通「Postgres 触发器 → `pg_notify` → Neon WebSocket `LISTEN` → Socket.IO 房间广播」的完整链路。动态生成 PL/pgSQL 触发器捕获行变更，服务端以「频道 → 连接」映射复用 LISTEN 长连接并做引用计数式释放，前端断线重连后自动补订阅；解决了 Serverless 数据库空闲挂起导致长连接被切断、推送静默失效的问题。

- **自动 REST API**：实现类 PostgREST 的能力，将 URL 查询串安全编译为 SQL。通过查询参数解析器拆分 `select / order / limit / offset` 与过滤条件，操作符走白名单，标识符统一正则校验防注入，值按类型格式化（字符串转义、数字/布尔直出、对象转 `jsonb`），并借助 `information_schema` 动态发现主键以支撑按行更新与删除。

- **双轨认证体系**：平台侧采用 access / refresh 双 Token 机制，写入 `httpOnly + SameSite=Lax` Cookie 防 XSS 与 CSRF，配合 `JwtAuthGuard → OrgRoleGuard` 鉴权链实现组织级 RBAC；项目侧为每个项目独立签发密钥与 `auth_jwt_secret`，支持邮箱密码、魔法链接邮件、Google / GitHub OAuth 三种登录方式，并采用懒建表按需创建用户表。

- **在线建表与 SQL 编辑器**：支持在浏览器内动态创建与修改表结构，将表单配置编译为 `CREATE TABLE`（类型映射、单/复合主键、自增、默认值白名单、外键约束）；SQL 编辑器基于 Monaco 并动态导入跳过 SSR，通过 Neon HTTP 事务原子执行 `search_path` 设置与用户 SQL，配合单语句校验与危险语句黑名单保障执行安全，同时记录查询耗时与影响行数历史。
