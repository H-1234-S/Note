# VoxClone 架构全景分析

## 项目定位
AI 驱动的文本转语音（TTS）+ 声音克隆 SaaS 平台，基于 Next.js 16 App Router 全栈架构。

---

## 一、整体技术栈评估

| 层级 | 技术选型 | 评价 |
|------|---------|------|
| 框架 | Next.js 16 + React 19 | 前沿，App Router + RSC |
| 类型安全 API 层 | tRPC v11 + Zod v4 + SuperJSON | **大厂级全栈类型安全方案** |
| 服务端状态 | TanStack React Query v5 | 缓存/预取/脱水/注水完整闭环 |
| 表单状态 | TanStack React Form v1 | 类型安全表单，性能优于 RHF |
| ORM | Prisma v7 + PostgreSQL | 类型生成到独立目录 |
| 认证/多租户 | Clerk (userId + orgId) | 企业级多组织隔离 |
| 计费 | Polar.sh SDK | Meter-based 用量计费 |
| 对象存储 | Cloudflare R2 (S3 API) | 音频文件存储+签名URL |
| 错误监控 | Sentry (tRPC middleware + global) | 生产级可观测性 |
| 音频引擎 | Chatterbox TTS API (openapi-fetch) | 类型安全的 API 客户端 |
| 音频可视化 | WaveSurfer.js v7 | 录制波形 + 播放波形 |
| CSS | Tailwind v4 + shadcn/ui | 原子化 + 无头组件 |


## 三、关键设计决策与模式

### 1. Feature-Based 目录结构
- `src/features/{模块}/` 下分层：`components/`、`hooks/`、`views/`、`contexts/`、`data/`、`lib/`
- 避免了按类型分组的深层嵌套，适合中型团队协作

### 2. tRPC + TanStack Query 全栈类型安全
- 后端定义 router → 前端直接用 `inferRouterOutputs<AppRouter>` 推导类型
- 零 API 类型声明文件，类型从 DB schema 到 UI 组件全链路安全
- `trpc/server.tsx` 使用 React `cache()` 保证同请求内 QueryClient 单例

### 3. SSR 数据预取 → 客户端水合
- Server Component 中 `prefetch()` → `<HydrateClient>` 包裹客户端组件
- 客户端用 `useSuspenseQuery`，自动使用水合后的缓存，无额外请求

### 4. 多租户数据隔离
- 所有 tRPC procedure 通过 `orgProcedure` 中间件注入 `orgId`
- 所有 DB 查询强制 `where: { orgId: ctx.orgId }`
- 音频文件路径：`voices/orgs/{orgId}/{voiceId}` 物理隔离

### 5. 优雅降级与韧性设计
- Billing 计费事件 "Fire-and-Forget"（静默失败不影响主流程）
- 声音被删除后显示 "Unavailable voice" 占位而非崩溃
- R2 存储失败时回滚 DB 记录（补偿事务）

## 四、React 高级模式运用

| 模式 | 使用位置 | 说明 |
|------|---------|------|
| Compound Components | `form.Field` → render props | TanStack Form 字段级状态隔离 |
| Custom Hook Composition | `useAudioRecorder` | 封装 MediaStream + WaveSurfer + RecordRTC 三方协调 |
| Context + Provider | `TTSVoicesProvider` | 避免 props drilling，配合 `useSuspenseQuery` |
| Higher-Order Pattern | `trpc/server.tsx` `createTRPCOptionsProxy` | tRPC 服务端代理 |
| Render Props | `VoiceCreateForm` `footer` prop | 让父组件控制表单提交按钮的渲染位置 |
| Dynamic Import | `useAudioRecorder` `import("recordrtc")` | 按需加载重型录音库 |
| Module-level Singleton | `trpc/client.tsx` `browserQueryClient` | 避免 Suspense 重渲染时重建 QueryClient |
